# Aula 06 — Servidor Web HTTP com Node.js

##  Sobre a aula

Nesta aula, foi desenvolvido um **servidor web utilizando o módulo HTTP nativo do Node.js**.

O objetivo é compreender como funciona a comunicação entre **cliente e servidor**, aprendendo a criar rotas, receber requisições HTTP e enviar respostas para o navegador.

O servidor é construído utilizando o módulo `http` do próprio Node.js, sem a utilização de frameworks como Express.



##  Objetivos

- Compreender o funcionamento de um servidor HTTP.
- Criar um servidor utilizando Node.js.
- Utilizar o módulo nativo `http`.
- Entender requisições e respostas HTTP.
- Trabalhar com métodos HTTP.
- Criar diferentes rotas.
- Definir códigos de status HTTP.
- Enviar respostas para o cliente.
- Testar o servidor através do navegador.
