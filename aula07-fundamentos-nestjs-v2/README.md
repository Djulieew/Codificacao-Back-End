# Aula 07 — Fundamentos do NestJS

Nesta aula foram estudados os fundamentos do **NestJS**, framework baseado em **Node.js e TypeScript** para desenvolvimento de aplicações backend eficientes, organizadas e escaláveis.

## 📚 Conteúdos estudados

- Introdução ao NestJS
- Estrutura de um projeto NestJS
- Configuração inicial do projeto
- Uso do **Node.js** com **TypeScript**
- Instalação das dependências com `npm install`
- Execução do projeto em diferentes ambientes
- Modo desenvolvimento e watch mode
- Execução em produção
- Testes unitários e testes E2E
- Organização e escalabilidade de aplicações backend
